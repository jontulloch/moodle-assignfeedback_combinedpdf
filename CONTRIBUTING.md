# Contributing

The repository contains the Moodle 5.2 Assignment feedback plugin `assignfeedback_combinedpdf`.

Use a separate branch and a pull request for every change. GitHub Actions tests PHP 8.3 against Moodle 5.2 with MariaDB and PostgreSQL and performs syntax, plugin-validation, PHPUnit, PHP coding-standard and PHPDoc checks. Explain any change to exported assessment information and include tests when practical.

Do not submit real student records, identifying filenames, production credentials, Turnitin reports, private links or institutional configuration. Report security issues privately as described in [SECURITY.md](SECURITY.md).

Contributors are responsible for ensuring they have the right to submit changes under the plugin's GPL v3-or-later licence. The maintainer should verify copyright ownership and third-party provenance before any public release.
